# Parallel Branch-and-Bound Solver for the Sequential Ordering Problem (SOP)

A state-of-the-art, multi-threaded exact solver for the **Sequential Ordering Problem (SOP)** (also known as the Precedence-Constrained Asymmetric Traveling Salesman Problem), specifically engineered for high-core-count NUMA architectures such as the **32-core AMD Ryzen Threadripper 2990WX**.

---

## Section 1: Requirements and Installations Required

### Operating System & Hardware Target
- **OS**: Ubuntu Linux (18.04 / 20.04 / 22.04 / 24.04 LTS or newer).
- **Target Processor**: AMD Ryzen Threadripper 2990WX (32 cores / 64 threads across 4 NUMA dies) or any x86_64 / ARM64 multicore processor.

### Compiler & Libraries
The solver is written in self-contained **C++20** using only standard POSIX/Linux threading (`pthread`) and standard library facilities. No external heavy MILP solvers (like CPLEX or Gurobi) are required.
