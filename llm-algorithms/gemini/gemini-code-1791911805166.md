# Sequential Ordering Problem (SOP) Solver - Ant Colony System (ACS-SOP) Edition

## Overview of Algorithm and Choice
This solver implements **Ant Colony System (ACS-SOP)**, the premier state-of-the-art metaheuristic specifically designed for the Sequential Ordering Problem:
1. **Ant Colony System (ACS)**: Utilizes adaptive pheromone matrices combined with heuristic cost visibility and pseudo-random proportional selection rules to naturally converge toward elite solutions.
2. **Parallel Multi-Core Execution**: Automatically distributes independent ant colonies across all available CPU cores using `concurrent.futures`.
3. **Bitmask Precedence Tracking**: Transitive closure precedence constraints are compiled into integer bitmasks for $O(1)$ CPU-level validation.

## Requirements and Installation
- **Language Version**: Python 3.7 or higher.
- **Dependencies**: Standard library modules only (`argparse`, `csv`, `math`, `os`, `random`, `sys`, `time`, `concurrent.futures`). Zero external packages required.
