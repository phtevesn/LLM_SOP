# State-of-the-Art Parallel Exact SOP Solver (`sop_solver`)

A high-performance, NUMA-aware parallel Branch-and-Bound solver in C++20 for finding and proving optimal solutions to the **Sequential Ordering Problem (SOP)** on TSPLIB `.sop` instances.

---

## Section 1: Requirements and Installations Required

The program is completely self-contained in a single C++20 source file (`sop_solver.cpp`) accompanied by a `Makefile`. It relies solely on the C++ Standard Library and POSIX threads (`pthread`) on Linux.

### System Requirements
- **OS:** Ubuntu Linux (20.04 LTS / 22.04 LTS / 24.04 LTS or newer)
- **Compiler & Build Tool:** `g++` (GCC 10 or newer with C++20 support) and `make`
- **Target CPU:** AMD Ryzen Threadripper 2990WX (32 Cores / 64 Threads, Zen+ Architecture) or any x86_64 processor.
